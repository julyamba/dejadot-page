# Echo

Landing page for [Echo](https://github.com/julyamba/echo), a one-thumb arcade game for Android.

- `index.html` — the whole page, including a playable demo of the game. No build step.
- `app-icon.png` — 512 x 512 app icon, also used as the favicon and share image.

Open `index.html` in a browser, or host the folder as a static site (for example GitHub Pages).

The Download button links to the newest release of `julyamba/echo` that has an `.apk` attached.
